# Pravidlá práce s aplikáciami

## Oddelenie aplikácií a GitHub repozitárov

- `Vyrobny_zapisnik` patrí výhradne do GitHub repozitára `https://github.com/Sebo706/Vyrobny_zapisnik.git`.
- `Moj_zapisnik` patrí výhradne do GitHub repozitára `https://github.com/Sebo706/Moj_zapisnik.git`.
- Pred úpravou vždy urč, ktorej aplikácie sa požiadavka týka, a pracuj iba v jej priečinku. Ak to nie je jednoznačné, najskôr sa opýtaj používateľa.
- Pred každým commitom alebo odoslaním na GitHub skontroluj koreň repozitára, aktuálny stav a adresu `origin`.
- Nikdy nepridávaj súbory druhej aplikácie ani dočasné pracovné kópie do nesprávneho repozitára.
- Commit ani odoslanie na GitHub nevykonávaj bez výslovného pokynu používateľa.
